How this page got here

Four stages run on every push to main.

  1. 1

    Push

    I commit index.html to GitHub.

  2. 2

    Test

    The workflow checks the HTML for errors.

  3. 3

    Deploy

    SCP copies the file to the EC2 instance.

  4. 4

    Live

    Nginx serves the new page to you.

The whole pipeline is one YAML file

GitHub reads .github/workflows/deploy.yml and runs it on its own servers. Nothing to install on my laptop.

The server address and SSH key live in GitHub Secrets, so they never appear in the code.

on:
  push:
    branches: [ main ]

jobs:
  deploy:
    runs-on: ubuntu-latest
    steps:
      - uses: actions/checkout@v4
      - uses: appleboy/scp-action@v0.1.7
        with:
          host: ${{ secrets.EC2_HOST }}
          target: /usr/share/nginx/html/
